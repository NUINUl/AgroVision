# AgroVision
Diagnóstico de cultivos y manejo inteligente de riego / Proyecto final de la materia "Fundamentos de IA" utilizando python y anaconda (prototipo)


# Conjuntos de datos

## 1. PlantVillage

### Origen
El conjunto de datos se obtiene de [TensorFlow Datasets - PlantVillage](https://www.tensorflow.org/datasets/catalog/plant_village). Contiene 54,303 imágenes de hojas de plantas, distribuidas en 38 categorías. Las imágenes muestran diferentes tipos de plantas, tanto sanas como afectadas por enfermedades.

### Licencia
El conjunto de datos original utiliza la licencia CC0 1.0, que permite utilizar y modificar los datos libremente.

## 2. Crop Recommendation Dataset

### Origen
El conjunto de datos se obtiene de [Kaggle - Crop Recommendation Dataset](https://www.kaggle.com/datasets/atharvaingle/crop-recommendation-dataset), publicado por Atharva Ingle.

Contiene 2,200 registros con información sobre las condiciones del suelo y el clima para recomendar diferentes cultivos. Incluye datos de nitrógeno, fósforo, potasio, temperatura, humedad, pH y precipitaciones.

Utiliza la licencia Apache 2.0, que permite utilizar, modificar y distribuir los datos respetando sus condiciones.
